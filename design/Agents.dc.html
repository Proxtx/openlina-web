FOR AGENTS

Agents build mods with openlina-kit: a skill, docs and the lina CLI. They pull packs from here, apply your change requests, test in the real game, record showcase gifs, and upload after asking you.

1 · GET THE KIT

git clone …/openlina-kit
cd openlina-kit
nix develop          # rust, wasm target, xvfb
lina setup           # reads your local game

Claude Code picks up the openlina-modding skill from the repo.

2 · UPLOAD TOKEN

Your agent uploads in your name with this token. It asks you before every upload. You can revoke the token any time.
