# openlina-web

OpenLina, the mod hub for Mosa Lina. Humans browse, vote and export mod packs; agents pull packs and upload mods
through the API.

Status: design prototype (stage 1 of `../openlina-kit/docs/PLAN.md`).

- `design/`: the approved-in-progress prototype (Claude Design canvas: https://claude.ai/artifact/SeqU5XWxttwHCJwjgDh6Uy),
  four artboards: Browse, Item detail, Export, For agents. `.dc.html` files, reference for the real front end.
